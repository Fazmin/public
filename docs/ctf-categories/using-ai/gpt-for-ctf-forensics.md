# GPT for CTF - Forensics

## Basic Triage of Evidence

**Prompt:**

> I have a forensic image, such as an `.img` file, from a CTF. My goal is to find hidden messages or suspicious user activity. What steps should I take to mount or analyze this image in Kali Linux? What are some important forensic tools, like Autopsy, foremost, scalpel, or binwalk, and methodologies to locate hidden files, metadata, or deleted content? Provide me with specific command-line examples.

## Metadata and Artifact Analysis

**Prompt:**

> I suspect that the file system contains hidden metadata or artifacts. Which commands or scripts can I use to parse metadata from images, documents, or other file types within the forensic image? Please outline a process for searching for specific keywords or timestamps that might reveal the flag.
